## Session 7 — ISS-019: BS→AD conversion fix

### Session information

- **Date:** 2026-11-21
- **Phase:** 1 — ISS-019 only (priority over Steps 5–6)
- **Objective:** Root-cause `daysBetweenBS`, regression tests first, fix arithmetic, prove 36525/36525, no Step 5

### Root cause (verified)

1. **Same-month / after day 1:** cursor formula effectively counted `(monthLength − d1) + d2` (and related paths), over-counting relative to exclusive day difference.
2. **Month 12 → 1:** after advancing year and resetting month to 1, the loop **added a full next Baisakh** before adding `date2.day` (~+30d; e.g. 2080-01-01 → 2023-05-15 instead of 2023-04-14).

### Algorithm correction

```
daysFromRefBs(date) = Σ year totals [REF..y) + Σ month lengths [1..m) + (day − 1)
daysBetweenBS(a, b) = daysFromRefBs(b) − daysFromRefBs(a)
```

Simple, auditable; no cursor rollover. Dataset / REF / public API / timezone behavior unchanged.

### Files changed

- `src/converters/bs-to-ad.ts` — absolute day-index `daysBetweenBS` (+ export for tests)
- `src/__tests__/conversion/days-between-bs.test.ts` — new arithmetic regressions
